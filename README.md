Omega Chess Project

Программа реализует игру в Омега-шахматы (12x12) с графическим интерфейсом на JavaFX и поддержкой двух режимов работы.

Что сделано:
Упрощенное игровое ядро: Реализована доска 12x12 с учетом уникальных клеток (эркеров) и базовая логика перемещения фигур.
Гейм менеджер: Управление очередностью ходов (белые/черные), проверка на наличие короля и завершение игры.
Бот: абсолютно тупой бот которые выбирает случайную фигуру и делает ей рандомный ход из достпуных
